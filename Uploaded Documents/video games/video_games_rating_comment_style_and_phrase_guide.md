# Video Games Rating Comment Style and Phrase Guide

Use this guide when drafting or reviewing comments for Video Games category-rating tasks. Its purpose is to help comments sound natural, personally reasoned, concise, and appropriately grounded without turning them into policy summaries.

This guide has two layers:

1. **Signed-Off Video Games Comment Patterns** — reusable wording approved through completed Video Games rating chats, with precise use conditions.
2. **General Video Games Comment Style Guidance** — project-specific writing rules, examples, and fallback structures.

---

## 1. Signed-Off Video Games Comment Pattern Library

Add new patterns or wording components only after a completed Video Games rating chat has gone through the separate abstraction-approval and processing workflow.

Before drafting novel wording, review the Signed-Off Comment Pattern Library and identify all patterns that materially apply to the current task.

Rank applicable patterns by relevance to the specific explanation needed.

Comment patterns are modular rather than exclusive. Do not assume that the entire final comment has to come from one pattern.

Use whatever approach best fits the task:

- If one pattern closely matches the case and its wording already expresses the relevant reasoning cleanly, use that pattern as the base and adapt the task-specific evidence.
- If several patterns apply, select the individual sentences, clauses, phrase structures, hedges, contrast constructions, or other wording from across those patterns that best express the current reasoning.
- A lower-ranked pattern may contain one phrase that fits a particular part of the explanation better than the primary pattern.
- Combine wording only when the pieces form a natural, coherent comment.
- Do not mechanically concatenate templates.
- Do not include every applicable pattern merely because it applies.
- Omit parts of an otherwise relevant pattern when they do not fit the current task.
- Novel wording remains available when the existing library does not contain a natural way to express an important part of the reasoning.

The aim is to reuse the strongest signed-off wording available at the level that is useful for the current task: complete template, sentence, clause, or individual phrase.

References such as “based on the visible evidence” should be used only when that accurately describes the basis being expressed in the comment. When verified research materially establishes the identity or meaning that drives the rating, use the appropriate researched-identity wording instead.

### Pattern relevance and selection

When several comment patterns apply, rank them according to how directly their wording expresses the reasoning that needs to appear in the final comment.

Consider:
1. whether the pattern addresses the decisive reason for the rating;
2. whether its wording fits the current evidence;
3. whether it expresses an important uncertainty or contrast accurately;
4. whether it contains useful language for a secondary reasoning point;
5. whether using it improves the comment without unnecessary explanation.

The highest-ranked pattern will often provide the main sentence structure, but this is not required.

Patterns are not votes and ranking is not a requirement to use every ranked pattern.

A pattern title and use condition should describe the decisive evidence relationship or classification boundary—not an incidental feature of its anchor example. Apply this test:

> If the anchor lacked this feature but the same wording logic still applied, should the feature remain part of pattern eligibility?

If not, keep it in an optional variant or anchor rather than the use condition.

### Instruction-reference patterns for borderline cases

Use these when the ambiguity comes from how the instructions cover a borderline category.

> Quizzes are not explicitly mentioned in the instructions, so I think the rating depends on how the quiz is framed. [Visible evidence explanation]. I would rate it [rating].

> The instructions do not clearly treat [category] by itself as Video Games, so I think the rating depends on the framing. Here, [visible framing], so I would rate it [rating].

### 1.1 Game-like digital component subordinate to a real-world activity

Use when the main offer is a real-world activity and a digital or game-like component supports that activity rather than being the main video-game product.

Approved base template:
> The main offer is [real-world activity] with a companion [quiz/app/AR/QR-code] component. Since it is presented as part of a real-world [trail/route/activity] rather than as a clear video game, I would rate it No.

Instruction-reference variant:
> The main offer is [real-world activity] with a companion [quiz/app] component. Quizzes are not explicitly mentioned in the instructions, so I think the rating depends on how the quiz is framed. Since it is framed as part of a real-world [trail/activity] rather than as a clear video game, I would rate it No.

Game-like wording variant:
> This uses some game-like [quiz/challenge/AR] wording, but the main offer appears to be [real-world activity]. Since the [quiz/app/AR] element supports a real-world experience rather than clearly advertising a video game, I would rate it No.

Short variant:
> The main offer appears to be [real-world activity] with a companion [quiz/app] element, not a clear video game. I would rate it No.

AR/trail-specific variant:
> The creative mentions [AR trails / quiz trails], but the offer appears to be a real-world trail experience with a digital companion. Since the main product is not clearly a video game, I would rate it No.

Phrases to use carefully:
- “standalone video game” — use carefully, because some valid video games are not standalone. “Clear video game” or “clearly framed as a video game” is usually safer.
- “framed” — useful for quiz borderline cases, but avoid repeating it too often in the same comment.
- “quiz app” — do not imply quiz apps can never be games. Pair it with the real-world trail/activity framing.
- “game-like” — useful for acknowledging ambiguity, but explain why the signal is not enough.
- “AR” — do not treat AR as automatically game-related; AR may support real-world tourism, education, navigation, or museum-style experiences.

Notes:
- This pattern is strongest when the comment names both sides: the game-like companion element and the real-world main offer.
- Use the instruction-reference variant when the borderline issue is specifically about whether quizzes count under the instructions.
- Use the shorter variant when the visible real-world framing is already obvious.
- Do not over-explain the whole framework in the comment. One to three sentences is usually enough.
- If the visible content clearly presents the app itself as the playable digital game, do not use this No pattern.

### 1.2 Research resolves a visible entity or meaning

Use when research resolves the identity or meaning of a visible advertiser, developer, publisher, company, brand, app, platform, game, service, website, name, word, phrase, or other clue, and that finding is decisive to the Video Games classification. The task evidence may be sparse, detailed, or otherwise non-decisive on its own.

Approved base template:
> [Entity] is a [video-game developer/publisher/game/platform/etc.], so I would rate this Yes.

Advertiser/publisher variant:
> [Advertiser] is a video-game developer and publisher, and the promotion appears to relate to its game business.

Research-identification variant:
> Research identifies “[term/name]” as [relevant identity], which makes the Video Games connection clear.

Non-game resolution variant:
> “[Term/name]” refers to [researched non-game identity or meaning], so it does not establish a Video Games offer. I would rate it No.

Ordinary-looking name variant:
> “[Phrase]” is the name of [game/product/service], rather than just generic wording.

Sparse-product variant:
> The creative itself is sparse, but [Product] appears to be a [game-related product type], so I would rate it Yes.

Mobile games variant:
> [Product] appears to be a premium mobile gaming portal.

Portal/platform variant:
> [Product] appears to be a gaming portal/platform.

Phrases to use carefully:
- “gaming platform” — useful, but can be broad. Prefer “mobile gaming portal,” “online games site,” or “game download platform” when the research supports a more specific label.
- “appears to be” — good when the researched classification retains some uncertainty; use direct wording when the identity is firmly established.
- “based on research” — usually prefer directly stating the verified identity when the source is sufficiently clear.
- “content platform” — too broad by itself unless paired with game-related wording.

Notes:
- Keep the comment short when the research evidence is clear.
- Name the entity type or researched meaning that supports the rating rather than merely saying it is “related.”
- Research may resolve the classification toward Yes or No; use the verified identity or meaning in the direction it supports.
- This pattern should not be used to force a resolution for every unclear creative. It applies only when the visible entity or meaning can be reliably identified and the research materially affects the Video Games classification.
- Make sure the researched identity corresponds to the exact entity in the task rather than a similarly named alternative.

### 1.3 Quiz as the main subject without clear game framing

Use when a quiz, trivia prompt, personality test, IQ test, knowledge quiz, or similar interactive question format is the main advertised subject, but it is not clearly presented as a video game, game app, online game, downloadable game, or gaming platform.

Approved base template:
> Quizzes are not explicitly mentioned in the instructions, so I think the rating depends on how the quiz is framed. This creative shows a [type of quiz], but it does not clearly present it as a video game. Based on the visible evidence, I would rate it No.

Short variant:
> This shows a [type of quiz], but it is not clearly framed as a video game or game app. Since quiz-style interaction alone is not enough, I would rate it No based on the visible evidence.

Useful Yes-with-uncertainty contrast variant:
> This looks more like a casual trivia quiz game than a generic quiz, but the creative does not explicitly show a game title, game app, or platform. I would rate it Yes with some uncertainty if the visible format is being treated as a playable casual game.

Phrases to use carefully:
- “quiz game” — only use when the visible framing supports a game interpretation, not just because there are answer buttons.
- “challenge” — a challenge can be game-like, but it is not enough by itself for Video Games.
- “test or assessment” — use carefully, because trivia quizzes are also a kind of test. If needed, distinguish “generic quiz/test framing” from “video-game framing.”
- “Quizzes are not explicitly mentioned in the instructions” — useful for explaining the borderline issue, but pair it with the visible reason for the rating.

Notes:
- The strongest No comments mention both parts: the instructions do not clearly cover quizzes by themselves, and the visible creative does not add clear game/app framing.
- Keep the comment grounded in visible evidence such as the question format, answer buttons, lack of game title, lack of app/game platform framing, or lack of score/progression elements.
- Do not over-explain the full framework in the rating comment. One or two sentences is usually enough.

### 1.4 Research-resolved game with supporting mechanic wording

Use when the task contains a researchable product or title clue but does not independently establish that the advertised subject is a game, research identifies the product as a digital game, and visible mechanic wording independently supports that identification. This relationship can occur regardless of the creative's overall information density.

Approved base template:
> “[Product]” appears to be a [digital puzzle/mobile/online] game, and the “[visible wording]” wording supports that identification by pointing to a [game mechanic].

Optional variants:
> “[Product]” appears to be a digital puzzle game. The creative itself is minimal, but “[visible wording]” is consistent with a simple casual game mechanic.

> The creative is sparse, but “[Product]” appears to be a [game type], and the “[visible wording]” line supports that interpretation.

> Based on the named product, “[Product]” appears to be a [digital puzzle/mobile/online] game. The visible “[visible wording]” wording also points in that direction.

Short variant:
> “[Product]” appears to be a digital puzzle game, and the visible “[visible wording]” line fits that kind of mobile/online game.

Phrases to use carefully:
- “makes it look like” — natural and useful for uncertainty, but should be paired with the researched product type when research is the main basis.
- “digital puzzle game” — use only when research supports that specific product type.
- “mobile or online game” — useful when the exact platform is not fully visible, but avoid using it if research only supports one specific platform.
- “Sort/Match/Solve wording” — do not treat mechanic-like wording as enough by itself unless the named product is clearly game-related.

Notes:
- This is best treated as a specialized form of the research-resolved entity-or-meaning pattern, not as a purely visible-evidence pattern.
- Keep the comment short. The useful structure is: researched product type first, visible mechanic support second.
- Do not say the task itself “clearly shows a game” when research is decisive. Use “appears to be” or similar wording when some uncertainty remains.
- “Sparse” or “minimal” may still be used when it accurately describes the creative, but information density is not an eligibility condition for this pattern.

### 1.5 Unresolved app-download offer after advertiser and product research

Use when the task presents a generic app-download or app-downloader offer, does not clearly identify the promoted app or service, and advertiser/product research still does not resolve the advertised subject. A game-branded advertiser name such as “123 Games” remains only a weak signal in that unresolved evidentiary state.

Approved base template:
> Not sure how to rate because the creative does not clearly indicate what is being advertised. The advertiser appears to be “[advertiser name],” which could point to video games, but I don’t think the creative itself gives enough information to rate it clearly either way.

Optional variants:
> The creative is not very explicit about what is being advertised. The advertiser appears to be “[advertiser name],” which could suggest a connection to video games, but the visible creative itself does not give enough information to make that clear.

> I’m unsure how to rate this because the creative only shows a generic app-download offer. “[Advertiser name]” could point to video games, but without a clear game title, gameplay, or game-download wording, I do not think there is enough visible evidence to classify it either way.

> The advertiser name “[advertiser name]” could be game-related, but the creative itself does not clearly show what app is being promoted. Based on the visible evidence, I do not think there is enough information to rate it clearly either way.

Research-aware variant:
> The creative does not clearly identify what is being advertised. “[Advertiser name]” could point to video games, but research does not reliably resolve the advertiser or promoted product, so I do not think there is enough information to rate it clearly either way.

Phrases to use carefully:
- “could point to video games” — useful for weak advertiser-name signals, but pair it with why the creative itself is still unclear.
- “not enough information” — specify that the missing information is about what app/product is being advertised.
- “app downloader” — do not treat this as automatically game-related; explain whether the visible evidence ties it to games.
- “very plausibly” — avoid stacking hedges like “very plausibly could,” which sounds less natural.

Notes:
- This pattern is best for comments supporting an uncertain or insufficient-evidence rating.
- Keep the wording grounded in the task evidence: advertiser name, generic app-download framing, lack of clear product/app identity, and the unresolved research result.
- Do not imply that advertiser branding is irrelevant. The point is that it is a weak signal unless the creative itself also supports a game-related interpretation.
- Before using this pattern, research the advertiser name. Use this pattern only if research does not reliably identify the advertiser as a covered game-related entity or otherwise resolve the advertised product.
- Do not call an advertiser name a merely “game-like” or “game-suggestive” signal solely because its identity was initially unfamiliar.
- This pattern can apply whether the creative is visually sparse or contains many generic elements; the decisive condition is that the advertised subject remains unresolved after research.

### 1.6 Unresolved advertised subject with only generic game-like wording

Use when the research sweep does not identify or meaningfully clarify the advertised subject and the task provides only generic game-like wording such as “play,” “challenge,” “fun,” or similar language. The decisive condition is that the subject remains unidentified, not that the creative is visually sparse or that it uses one particular word.

Approved base template:
> Not sure how to rate because the creative only uses vague “[generic game-like wording].” The ad does not identify what is being advertised, and research does not resolve it. Flagging it as unrateable seems most appropriate.

Creative-consistency variant:
> Not sure how to rate because the creative only makes a vague reference to “[play/play-related wording].” The creative contains too little information to tell what is even being advertised, so marking it unrateable seems most appropriate.

Short variant:
> The creative only makes a vague reference to “[play/play-related wording],” but does not show enough information to tell what is even being advertised. I would mark it unrateable.

Visible-detail variant:
> The creative only shows [generic CTA / vague play wording] and does not identify a game, app, advertiser, or product. There is too little information to tell what is even being advertised, so I would mark it unrateable.

Research-aware variant:
> The creative only makes a vague reference to “[wording],” and research does not identify a product or relevant secondary meaning. There is still too little information to tell what is being advertised, so I would mark it Unrateable.

Phrases to use carefully:
- “what is even being advertised” — useful when the problem is assessability, not just classification uncertainty. It emphasizes that there is too little visible content to identify the product at all.
- “what is actually being advertised” — use carefully here, because it can sound like the product has several possible interpretations rather than there being too little information to assess.
- “vague reference to playing” — useful, but pair it with the missing product-identification reason.
- “not sure how to rate” — appropriate when the uncertainty is explained by lack of visible evidence.

Notes:
- Keep this pattern focused on lack of assessability. The core reason is not simply that “play” or another game-like word could mean different things; it is that the task and completed research sweep do not identify the advertised product.
- Do not use this pattern when the product is identifiable and the issue is only whether it qualifies as Video Games. In that case, give the best Yes/No rating and explain the classification uncertainty.
- If a specific entity or phrase is visible and research resolves it as game-related or non-game, use the research-resolved entity-or-meaning pattern instead.
- Use this pattern only after the manual's research sweep fails to identify or meaningfully clarify the advertised subject.
- An unfamiliar word or phrase should not be treated as generic “play” wording until plausible named-entity or specialized-meaning interpretations have been checked.
- “Sparse” may still be used in a comment when it accurately describes the anchor creative, but it is not an eligibility condition for this pattern.

### 1.7 Game-like mechanic, non-game product framing

Use when the visible creative shows an app or activity with a game-like mechanic, but the main visible framing is a non-game product type such as drawing, coloring, artwork creation, photo editing, or another utility/creative activity.

Approved base template:
> This looks like an ad for a [non-game app/activity type]. It has a [game-like mechanic] mechanic, but the visible text presents it as [non-game framing] rather than clearly advertising it as a video game.

Poly-art version:
> This looks like an ad for a poly-art drawing app. Poly-art drawing apps have a puzzle-like mechanic, but the visible text presents it as creating artwork rather than clearly advertising it as a video game.

Short variant:
> This looks more like a [non-game app/activity type] than a clearly advertised game. The [mechanic] is somewhat game-like, but the visible text does not clearly present it as a video game.

Visible-evidence variant:
> The creative shows [visible mechanic], which feels somewhat puzzle-like. But the visible wording focuses on [creating/revealing/editing/etc.] rather than playing a video game, so I would rate it No.

Phrases to use carefully:
- “puzzle-like” — useful for acknowledging the ambiguity, but pair it with why the mechanic is not enough.
- “does not qualify as a game” — can sound too broad. Prefer “does not clearly present it as a video game” unless the evidence is very clear.
- “in my opinion” — usually weaker than needed. Ground the comment in visible text instead.
- “drawing apps are not games” — too absolute; some drawing/puzzle apps could qualify if clearly framed as games.

Notes:
- This pattern is strongest when the comment names both sides: the game-like mechanic and the non-game framing.
- Keep the wording short. The comment does not need to explain the whole manual; it only needs to say why the visible creative is not clearly Video Games.
- Use “visible text” or “visible wording” when the decision depends on not assuming hidden landing-page behavior.
- If a named product or potentially specialized term is present, research it before relying on this visible-framing pattern. Verified product identity can outweigh an initial interpretation based only on surface wording.

### 1.8 Cumulative implicit game framing without explicit game label

Use when the creative does not explicitly say “game,” “video game,” or the exact game title, but several visible details strongly point to a covered digital game type.

Approved base template:
> The creative does not explicitly mention “[exact game/game label],” but the references to [visible clue 1], [visible clue 2], and [visible clue 3] strongly indicate a [game type] digital game.

Spider/card-game version:
> The creative does not explicitly mention “Spider Solitaire,” but the references to “Spider,” cards, card faces, and a challenge strongly indicate a customizable Spider Solitaire-style digital card game.

Short variant:
> The creative does not say “game” directly, but the visible references to [clues] strongly point to a [game type] digital game.

More cautious variant:
> The creative is not explicit, but the combination of [visible clue 1], [visible clue 2], and [visible clue 3] makes it look like a [game type] digital game.

Opposite-direction variant:
> The creative has some game-like wording, but the visible clues do not strongly identify a video game. Since it is framed more as [non-game framing] than as a clear digital game, I would not treat it as Video Games based on the visible evidence.

Phrases to use carefully:
- “strongly indicate” — use when there are several reinforcing clues, not just one weak hint.
- “does not explicitly mention” — useful for explaining why the comment is interpretive, but pair it with the visible clues that support the rating.
- “challenge” — helpful as a supporting clue, but not enough by itself.
- “[game]-style” — useful when the exact title is not shown, but avoid overclaiming if the visible evidence only weakly suggests the game.

Notes:
- This pattern is for converging implicit evidence. It should not be used when the clues are generic, isolated, or insufficiently convergent to identify a covered digital game.
- The comment should name the visible clues, not just say the creative “seems game-related.”
- Use a cautious variant when the evidence supports the rating but does not make the exact game title fully explicit.
- Research potentially meaningful names and phrases before relying solely on cumulative implicit inference. If research directly identifies the product or term, prefer wording that states the verified identity rather than presenting the conclusion as purely implicit.

### 1.9 Verified game-publisher promotion without a specific title

Use when the task evidence or reliable research identifies a video-game developer or publisher as the subject of a company- or portfolio-level promotion, such as rewards, events, celebrations, or releases, but no individual game is named.

Approved base template:
> [Advertiser] is a video-game developer and publisher, and the [promotion/event] appears to relate to its game business. Even though no specific title is shown, I would rate it Yes.

Game-focused variant:
> [Advertiser] is a video-game developer and publisher, and the visible [rewards/events/celebration] appear to relate to its games. Even though no specific title is shown, I would rate it Yes.

Short variant:
> This is a promotion for [Advertiser], a video-game developer/publisher. A specific game is not named, but the publisher-level promotion still falls under Video Games.

Huuuge anchor variant:
> Huuuge is a mobile game developer and publisher, and the anniversary promotion’s free gifts and limited-time events appear to relate to its games. Even though no specific title is shown, I would rate it Yes.

Phrases to use carefully:
- “appears to relate to its games” — useful when the visible promotion is compatible with the publisher’s game business but does not name a game.
- “publisher-level promotion” — accurate but more abstract; prefer naming the visible rewards, events, celebration, or release when possible.
- “still falls under Video Games” — use only when the game company or its publishing/marketing activity is the advertised subject.

Notes:
- Do not use this pattern merely because a game-company name or logo appears incidentally.
- If the creative clearly advertises recruitment, investor relations, hardware, unrelated merchandise, education, or another non-game subject, describe that subject instead.
- Prior familiarity or fame is not required; reliable identification and the publisher promotion's role as the main subject are the decisive conditions.

### 1.10 Research resolves apparently generic wording

Use when wording in the creative could be read as ordinary language, but research establishes that it is actually the name of or reference to a relevant game, product, company, service, feature, event, or other entity.

Approved base template:
> “[Visible wording]” appears generic by itself, but it refers to [researched identity], which is [relevant Video Games connection].

Short variant:
> “[Visible wording]” is actually [researched identity], which makes the creative game-related.

Entity-name variant:
> “[Visible wording]” is the name of [game/app/platform/etc.], rather than just generic [ordinary-language interpretation].

Phrases to use carefully:
- “actually” — useful for correcting a plausible surface reading, but unnecessary when there was no real ambiguity.
- “appears generic” — do not use if the term is obviously a proper name.
- “based on research” — usually prefer directly stating the verified identity when the source is sufficiently clear.

## 2. Core Writing Goal

Write like a careful human rater briefly explaining:

1. what the creative or page advertises or discusses;
2. which Video Games connection or boundary is decisive;
3. why that supports the rating.

A good comment should be:

- specific;
- grounded in the task evidence—visible evidence and, where relevant, verified research tied to it;
- concise;
- natural in phrasing;
- appropriately direct or cautious;
- focused on the reason that changes the rating.

The comment is not a substitute for the full task analysis. Include only the evidence and distinction needed to make the rating understandable.

## 3. Use Plain, Concrete Wording

Prefer ordinary language over abstract evaluation language.

### Prefer

- “The creative advertises…”
- “The page is about…”
- “The visible text shows…”
- “Research identifies this as…”
- “This looks more like a drawing app than a video game.”
- “The product remains unidentified after research.”

### Avoid

- “The content demonstrates meaningful categorical alignment.”
- “The offering exhibits insufficient Video Games specificity.”
- “The advertisement maintains thematic adjacency without decisive category correspondence.”
- “The creative partially fulfills the applicable classification criteria.”

### Rule

Use the simplest wording that accurately explains the classification.

---

## 4. State the Decisive Reason

Do not stop at words such as “related,” “relevant,” “generic,” “game-like,” or “not a game.” State what makes the subject positive, negative, or unassessable.

Useful decisive reasons include:

- a named or clearly shown digital game;
- gameplay, levels, missions, characters, scoring, game currency, or another strong game structure;
- a verified game, developer, publisher, platform, portal, retailer, media/reference page, reward system, or development product covered by the manual;
- several specific clues that converge on a covered game even without an explicit game label;
- a game-like component that remains subordinate to a real-world or non-game main activity;
- a quiz or interactive prompt without clear video-game framing;
- an identifiable utility, art, education, tourism, or other non-game product whose mechanic is only game-like;
- an advertised subject that remains unidentified after the full research sweep.

### Prefer

> The creative shows a connect-the-dots mechanic, but the visible wording presents the product as an artwork-creation app rather than a video game.

### Avoid

> The creative is only somewhat game-related.

### Rule

Name the evidence relationship, researched identity, main-subject distinction, or assessability problem that drives the rating.

---

## 5. Use a Natural Reasoning Flow

A useful visible-evidence structure is:

> The creative advertises [subject]. It includes [potentially game-like clue], but [decisive main-subject or framing distinction]. I would rate it [rating].

A useful research-resolved structure is:

> Research identifies [visible name or wording] as [verified identity]. Since [Video Games connection or exclusion], I would rate it [rating].

A useful cumulative-evidence structure is:

> The creative does not say “[game label]” directly, but [clue 1], [clue 2], and [clue 3] together point to [covered game type]. I would rate it [rating].

For Unrateable:

> The creative only shows [limited clues], and research does not identify the advertised subject. There is too little information to classify it, so I would mark it Unrateable.

Use these structures when helpful, but do not force every comment into the same sentence pattern.

---

## 6. Vary Sentence Length and Rhythm

Comments sound more natural when they do not all have the same shape.

### Prefer

> Huuuge is a mobile game developer and publisher. The anniversary promotion’s rewards and limited-time events appear to relate to its games, so I would rate it Yes.

### Avoid

> The advertiser is established as a mobile video-game developer and publisher. The promotion is established as relating to its game portfolio. Therefore, the content is established as belonging to Video Games.

### Rule

Mix short and medium-length sentences. Do not polish every comment into the same formal rhythm.

---

## 7. Use Certainty and Hedging Deliberately

Be direct about visible or verified facts:

- “The text says…”
- “The page promotes…”
- “The product is…”
- “The creative does not identify…”
- “Research identifies…”

Use mild hedging for interpretation or a research finding that retains uncertainty:

- “appears to”;
- “seems to”;
- “points toward”;
- “is more consistent with”;
- “could suggest”;
- “likely refers to.”

### Prefer

> The visible text is a little ambiguous, but the references to cards, card faces, and a challenge strongly point to a Spider Solitaire-style digital card game.

### Avoid

> This may perhaps potentially be interpreted as possibly related to a game.

### Rule

Hedging should identify the uncertain part, not weaken every statement in the comment.

---

## 8. Keep Professional Imperfection

Comments should sound personally written rather than generated. Slightly conversational phrasing is acceptable when it remains clear.

### Natural

- “points in that direction, but…”;
- “not enough by itself”;
- “looks more like…”;
- “I think the rating depends on…”;
- “there is too little information to tell…”;
- “the creative itself is not very explicit.”

### Over-polished

- “insufficiently targeted toward the operative category”;
- “fails to satisfy the dominant classificatory criterion”;
- “maintains game-related adjacency without categorical fulfillment.”

### Rule

Prefer a clear human explanation over maximal formal polish. Avoid slang, jokes, and careless absolutes.

---

## 9. Explain the Judgment Without Reproducing the Framework

Use the manual internally, but do not turn the comment into a policy summary. Mention an instruction boundary only when it helps explain why the case is borderline.

### Useful instruction reference

> Quizzes are not explicitly mentioned in the instructions, so I think the rating depends on how the quiz is framed. This creative shows a trivia quiz, but it does not clearly present it as a video game, so I would rate it No.

### Weak instruction reference

> The instructions do not mention quizzes, so No.

The second version does not explain why the current task fits the boundary.

### Rule

Pair instruction references with the concrete task-specific reason.

## 10. Distinguish Game-Like Signals From a Covered Video Games Subject

A quiz, challenge, “play” wording, AR layer, QR code, app CTA, puzzle-like mechanic, or playful visual style can be compatible with gaming without establishing that the main advertised subject belongs to Video Games.

Ask what the combined task evidence identifies:

- A game-like component may remain subordinate to a real-world or non-game main activity.
- A quiz is not automatically a video game.
- A utility, drawing, coloring, education, tourism, or creative app does not become a game merely because its interaction feels puzzle-like.
- Generic “play,” “fun,” or “challenge” wording does not identify an unknown product.
- Several generic game-like clues do not become decisive merely by accumulation.
- Several specific, mutually reinforcing clues can identify a covered digital game without an explicit “game” label.
- Reliable research can establish a covered game, platform, portal, developer, publisher, or publisher-level promotion even when the creative does not name a specific game.

### Rule

Explain whether the evidence establishes a covered Video Games subject, merely supplies a game-like signal, or fails to identify the subject at all.

---

## 11. Describe Research Accurately

When research materially contributes, state the useful verified fact rather than vaguely saying “based on research.”

### Prefer

> Slamdjam appears to be a premium mobile gaming portal, so I would rate it Yes.

> “Cake Sort” appears to be a digital puzzle game, and the visible “Sort cake!” wording supports that identification.

> “[Term]” refers to a non-game service, so it does not establish a Video Games offer.

### Avoid

> Based on research, this is Video Games.

### Rules

- Name the resolved identity, meaning, product type, or company role.
- Make sure the researched finding corresponds to the exact task clue rather than a similarly named entity.
- Do not imply that research establishes more than the source supports.
- If research is decisive and visible wording merely supports it, distinguish those roles naturally.
- Do not describe researched identification of something visibly present as hidden landing-page behavior.
- Do not import unsupported unseen post-click content.

---

## 12. Avoid Common AI-Sounding Patterns

### Avoid excessive abstract nouns

- alignment;
- fulfillment;
- correspondence;
- differentiation;
- categorization;
- optimization;
- thematic relevance;
- categorical applicability.

### Avoid inflated phrasing

- “clearly demonstrates”;
- “effectively establishes”;
- “substantially fulfills”;
- “strongly evidences”;
- “notwithstanding”;
- “commercially adjacent.”

### Avoid mechanical templates

- every comment beginning “The creative appears to…”;
- every comment ending “Therefore, I would rate…”;
- every comment using three equally long, perfectly balanced sentences;
- repeating “framed,” “visible evidence,” or “game-related” several times;
- listing the entire indicator table in prose.

### Rule

Vary the wording while keeping the decisive logic clear.

## 13. Better and Worse Video Games Comment Examples

These examples are illustrative rather than additional signed-off patterns. They demonstrate style and evidence relationships without creating new case precedent.

### Game-like companion subordinate to a real-world activity

**Prefer**

> The main offer is a real-world trail with a companion quiz app. Since the quiz supports the physical activity rather than being presented as the main video game, I would rate it No.

**Avoid**

> The content is game-adjacent but insufficiently aligned with Video Games.

### Verified publisher-level promotion

**Prefer**

> Huuuge is a mobile game developer and publisher, and the anniversary rewards and limited-time events appear to relate to its games. Even though no specific title is shown, I would rate it Yes.

**Avoid**

> The advertiser is in gaming, so this is relevant.

### Cumulative implicit game framing

**Prefer**

> The creative does not explicitly mention “Spider Solitaire,” but the references to “Spider,” cards, card faces, and a challenge strongly indicate a Spider Solitaire-style digital card game.

## 14. Drafting Checklist

Before finalizing a comment, check:

- Did I state what the creative or page advertises or discusses?
- Did I state the actual reason for the rating?
- Did I distinguish the main covered subject from a merely game-like component or signal?
- Did I name the decisive identity, evidence relationship, framing boundary, or missing information?
- If several clues matter, did I explain how they converge rather than merely list them?
- If research materially contributed, did I state the useful verified finding?
- Did I avoid importing a similarly named entity or unsupported post-click content?
- Did I use direct wording for facts and hedge only the interpretive part?
- Is the comment concise enough for a rating task?
- Could the same comment fit many unrelated creatives? If yes, make it more specific.
- Did I avoid overusing framework vocabulary?
- Does it sound like a person wrote it?
- If I reused signed-off wording, did I preserve its precise use condition and adapt only the task-specific evidence?

## 15. Default Comment Structures

Use these only as fallbacks when no signed-off pattern or wording component expresses the reasoning naturally.

### Yes — directly established subject

> The creative advertises [game/product/service/page type]. Since [decisive visible evidence], I would rate it Yes.

### Yes — research-resolved subject

> “[Visible name or wording]” refers to [verified game-related identity]. Since [connection to a covered Video Games subject], I would rate it Yes.

### No — identifiable non-game main subject

> The creative advertises [non-game subject]. Although [game-like clue] points in that direction, the main product is presented as [non-game framing] rather than a video game, so I would rate it No.

### No — game-like component is subordinate

> The main offer is [real-world or non-game activity] with a [game-like component]. Since that component supports the broader activity rather than being the main video-game product, I would rate it No.

### Unrateable

> The creative only shows [limited generic clues], and research does not identify what is being advertised. There is too little information to classify it, so I would mark it Unrateable.
