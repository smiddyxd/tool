# Weight Loss Rating Comment Style and Phrase Guide

Use this guide when drafting or reviewing comments for Weight Loss category-rating tasks. Its purpose is to help comments sound natural, personally reasoned, concise, and appropriately grounded without turning them into policy summaries.

This guide has three different layers:

1. **Signed-Off Weight Loss Comment Patterns** — wording approved through completed Weight Loss rating chats, with precise use conditions.
2. **Optional Cross-Category Wording Bank** — adaptable language translated from useful Video Games comments. It is inspiration, not Weight Loss precedent.
3. **General Weight Loss Comment Style Guidance** — project-specific writing rules and examples.

---

## 1. Signed-Off Weight Loss Comment Pattern Library

No signed-off Weight Loss pattern has been added in this transposition round. Add patterns here only after a completed Weight Loss rating chat has gone through the separate abstraction-approval and processing workflow.

When patterns are present, review the complete library before drafting novel wording and identify all patterns that materially apply.

Rank applicable patterns by how directly their wording expresses the reasoning that needs to appear in the current comment.

Comment patterns are modular rather than exclusive:

- If one pattern closely matches and already expresses the reasoning naturally, use it as the base and adapt the task-specific evidence.
- If several patterns apply, select the individual sentence, clause, phrase structure, hedge, contrast construction, or phrase that best expresses each part of the reasoning.
- A lower-ranked pattern may contain the best phrase for one secondary point.
- Do not concatenate complete templates mechanically.
- Do not include every applicable pattern merely because it applies.
- Omit parts of an otherwise relevant pattern when they do not fit.
- Novel wording remains available when the library has no natural component for an important point.

Patterns are not votes. Ranking does not require using every ranked pattern, and the highest-ranked pattern does not have to provide the main sentence structure.

A pattern title and use condition should describe the decisive evidence relationship or category boundary—not an incidental feature of its anchor example. Apply this test:

> If the anchor lacked this feature but the same wording logic still applied, should the feature remain part of pattern eligibility?

If not, keep it in an optional variant or anchor rather than the use condition.

### Future signed-off pattern format

```md
### [Pattern number and reusable title]

Use when [precise condition based on task evidence, including any materially relevant verified research].

Approved base template:
> [Signed-off reusable wording.]

Optional variants:
> [Variant.]

Phrases to use carefully:
- “[phrase]” — [why it needs care]

Notes:
- [Adaptation or boundary note.]
```

## 2. Optional Cross-Category Wording Bank

This section contains transferable language from useful Video Games comments and patterns. It is deliberately less authoritative than the signed-off library.

Use it as inspiration when the wording fits naturally. Adapt it to the Weight Loss evidence and reasoning. Do not import the original Video Games eligibility logic, and do not let a phrase override the Weight Loss manual.

### Identifying the main offer or purpose

- “The main offer appears to be…”
- “This looks like an ad for…”
- “The creative is centered on…”
- “The page presents this as…”
- “The visible wording focuses on…”
- “The advertised purpose appears to be…”
- “The exact offer is…”

### Acknowledging a directional clue without overstating it

- “[Clue] points in that direction, but…”
- “This has some weight-loss-adjacent wording, but…”
- “The imagery is compatible with weight loss, but…”
- “That is a supporting clue rather than the main basis for the rating.”
- “The wording lightly supports that interpretation.”
- “This could suggest a connection to weight loss, but it does not establish one by itself.”
- “The signal is relevant, but not specific enough on its own.”

### Explaining a framing or purpose boundary

- “I think the rating depends on how [element] is framed.”
- “The decisive issue is whether…”
- “This is presented as [general health purpose] rather than [weight-loss purpose].”
- “This looks more like [general wellness/fitness/nutrition] than a clear weight-loss offer.”
- “The same [product/method] could rate differently under a different pitch.”
- “Here, the main purpose appears to be…”
- “The category-adjacent element supports the broader offer rather than defining it.”

### Explaining cumulative implicit evidence

- “The creative does not say ‘weight loss’ directly, but…”
- “The combination of [clue 1], [clue 2], and [clue 3] strongly points to…”
- “Several visible details reinforce the same interpretation.”
- “Taken together, these clues are more specific than general health imagery.”
- “The clues point toward healthy living, but they do not converge specifically on weight loss or fat reduction.”
- “Multiple generic health signals do not become weight-loss-specific merely by accumulation.”

### Stating researched identity or meaning

- “Research identifies [name] as…”
- “[Visible wording] is the name of…”
- “[Visible wording] appears generic by itself, but it refers to…”
- “[Product/program] appears to be…”
- “The creative itself does not explain the term, but its verified meaning is…”
- “The researched identity is the main basis for the rating; the visible wording provides secondary support.”
- “Research resolves this toward No because…”

### Explaining insufficient information

- “The creative does not clearly identify what is being advertised.”
- “There is too little information to tell what is even being advertised.”
- “The advertiser name could point in that direction, but research does not resolve the promoted product.”
- “The subject remains unidentified after the research sweep.”
- “This is an assessability problem rather than ordinary classification uncertainty.”

### Distinguishing assessable uncertainty from Unrateable

- “The offer itself is understandable; the uncertainty is whether it falls under Weight Loss.”
- “This is assessable but borderline, so I would still give the best Yes/No rating.”
- “The visible text is a little ambiguous, but…”
- “I would rate it [Yes/No] with some uncertainty.”
- “I would mark it Unrateable because the advertised subject cannot be identified.”

### Concise rating conclusions

- “I would rate it Yes.”
- “I would rate it No.”
- “I would mark it Unrateable.”
- “That is enough to support a Yes rating.”
- “That is not enough by itself to establish a Weight Loss offer.”
- “Even though [missing explicit element], I would still rate it Yes.”
- “Since the pitch is [competing purpose] rather than weight loss or fat reduction, I would rate it No.”

### Phrases to use carefully

- **“generic”** — specify what is generic and relative to what. Prefer “generic health imagery” or “too generic to establish a weight-loss purpose” over “the ad is generic.”
- **“framed”** — useful for purpose boundaries, but avoid repeating it several times in one comment.
- **“appears to”** — appropriate for interpretation or uncertain researched identity; use direct wording for clear visible facts.
- **“clearly”** — reserve it for genuinely strong evidence.
- **“based on the visible evidence”** — use only when that accurately describes the basis. If research materially contributed, state the researched identity or use “task evidence.”
- **“weight-loss-related”** — sometimes too vague. When possible, name the actual relationship: dieting, calorie reduction, appetite control, fat burning, slimming, or another covered purpose.
- **“not a weight-loss product”** — avoid categorical product claims when the real point is that this particular creative does not promote a weight-loss purpose.

## 3. Core Writing Goal

Write like a careful human rater briefly explaining:

1. what the creative or page promotes;
2. which Weight Loss boundary is decisive;
3. why that supports the rating.

A good comment should be:

- specific;
- grounded in the task evidence—visible evidence and, where relevant, verified research tied to it;
- concise;
- natural in phrasing;
- appropriately direct or cautious;
- focused on the reason that changes the rating.

The comment is not a substitute for the full task analysis. Include only the evidence and distinction needed to make the rating understandable.

---

## 4. Use Plain, Concrete Wording

Prefer ordinary language over abstract evaluation language.

### Prefer

- “The creative promotes…”
- “The page shows…”
- “The visible text mentions…”
- “This points to general health rather than weight loss.”
- “The program is intended for athletic preparation, not losing weight.”
- “Research identifies this as a fat-reduction treatment.”
- “There is not enough information to tell what is being advertised.”

### Avoid

- “The content demonstrates meaningful categorical alignment.”
- “The offering exhibits insufficient Weight Loss specificity.”
- “The advertisement maintains thematic adjacency while lacking decisive category correspondence.”
- “The creative partially fulfills the relevant classification criteria.”

### Rule

Use the simplest wording that accurately explains the classification.

---

## 5. State the Decisive Reason

Do not stop at words such as “related,” “relevant,” “generic,” or “not weight loss.” State what makes the offer positive, negative, or unassessable.

Useful decisive reasons include:

- an explicit weight-loss, fat-loss, fat-burning, slimming, waist-reduction, or inch-loss claim;
- an Official positive product, plan, counter, procedure, or treatment category;
- a researched exact product or program identity;
- a meaningful weight-management service;
- general health, nutrition, fitness, or wellness framing without a covered purpose;
- a clearly competing purpose such as athletic preparation, disease management, weight gain, energy, relaxation, or unrelated cosmetic treatment;
- an incidental rather than meaningful weight-loss reference;
- several specific clues that converge on weight loss;
- several generic health clues that do not converge on weight loss;
- an unidentified advertised subject after research.

### Prefer

> The healthy-food and exercise imagery point toward healthy eating and activity, but they are too general to establish that the offer is aimed at weight loss or fat reduction.

### Avoid

> The creative is too generic and not clearly relevant.

### Rule

Name the evidence relationship or purpose boundary that drives the rating.

---

## 6. Use a Natural Reasoning Flow

A useful structure is:

> The creative promotes [subject or purpose]. [Potentially relevant clue] points toward [interpretation], but [decisive boundary]. I would rate it [rating].

Another useful structure is:

> Research identifies [visible entity] as [verified identity]. Since [connection to the advertised purpose], I would rate it [rating].

For Unrateable:

> The creative only shows [limited clues], and research does not identify the advertised subject. There is too little information to classify it, so I would mark it Unrateable.

Use these structures when helpful, but do not force every comment into the same sentence pattern.

---

## 7. Use Certainty and Hedging Deliberately

Be direct about visible or verified facts:

- “The text says…”
- “The page promotes…”
- “The product is…”
- “This does not mention…”
- “Research identifies…”

Use mild hedging for interpretation:

- “appears to”;
- “seems to”;
- “points toward”;
- “is more consistent with”;
- “could suggest”;
- “likely refers to.”

### Prefer

> The imagery points toward general health, but it does not specifically establish a weight-loss purpose.

### Avoid

> This may perhaps potentially be interpreted as possibly related to weight loss.

### Rule

Hedging should identify the uncertain part, not weaken every statement in the comment.

---

## 8. Keep Professional Imperfection

Comments should sound personally written rather than generated. Slightly conversational phrasing is acceptable when it remains clear.

### Natural

- “points in that direction, but…”
- “not enough by itself”;
- “more like general health”;
- “I think the rating depends on…”;
- “there is too little information to tell…”;
- “this looks like…”

### Over-polished

- “insufficiently targeted toward the operative category”;
- “fails to satisfy the dominant promotional-purpose criterion”;
- “maintains health-related adjacency without categorical fulfillment.”

### Rule

Prefer a clear human explanation over maximal formal polish. Avoid slang, jokes, and careless absolutes.

---

## 9. Explain the Judgment Without Reproducing the Framework

Use the manual internally, but do not turn the comment into a policy summary. Mention the instruction boundary only when it helps explain why the case is borderline.

### Useful instruction reference

> General fitness is outside the category unless the offer is aimed at weight loss or fat reduction. Here, the creative promotes activity and healthy habits without establishing that purpose, so I would rate it No.

### Weak instruction reference

> General fitness is excluded, so No.

The second version does not explain why the current task fits that exclusion.

### Rule

Pair instruction references with the concrete task-specific reason.

---

## 10. Distinguish Broad Health Relatedness From Weight Loss Targetedness

Health, food, exercise, fitness, wellness, transformation, or medical content can be associated with losing weight without promoting it.

Ask what purpose the task establishes:

- General health or wellbeing alone is not Weight Loss.
- Exercise alone is not Weight Loss.
- Healthy food imagery alone is not Weight Loss.
- A challenge format alone is not Weight Loss.
- A provider that sometimes offers weight management is not enough by itself.
- Several generic health signals do not automatically become weight-loss-specific.

At the same time, do not require an explicit “weight loss” phrase when the Official guidance or specific combined evidence establishes a covered purpose.

### Rule

Explain whether the evidence establishes a Weight Loss purpose, not merely whether it sits in the same broad health area.

---

## 11. Describe Research Accurately

When research materially contributes, state the useful verified fact rather than vaguely saying “based on research.”

### Prefer

> [Program] is specifically marketed as a weight-loss plan, so I would rate it Yes.

> [Product] is a general fitness supplement, and this creative does not promote a weight-loss purpose, so I would rate it No.

### Avoid

> Based on research, this is Weight Loss.

### Rules

- Name the resolved identity, meaning, or marketed purpose.
- Do not imply that research establishes more than the source supports.
- Do not import another campaign or possible product use into the current offer.
- If research is decisive and visible wording merely supports it, say so naturally.
- Do not discuss medical effectiveness unless it is necessary to explain what the ad claims—and even then, do not evaluate the claim as part of the rating.

---

## 12. Avoid Common AI-Sounding Patterns

### Avoid excessive abstract nouns

- alignment;
- fulfillment;
- correspondence;
- differentiation;
- categorization;
- optimization;
- thematic relevance;
- promotional intentionality.

### Avoid inflated phrasing

- “clearly demonstrates”;
- “effectively establishes”;
- “substantially fulfills”;
- “strongly evidences”;
- “notwithstanding”;
- “commercially adjacent.”

### Avoid mechanical templates

- every comment beginning “The creative appears to…”;
- every comment ending “Therefore, I would rate…”;
- every comment using three equally long, perfectly balanced sentences;
- repeating “framed” or “visible evidence” several times;
- listing the entire indicator table in prose.

### Rule

Vary the wording while keeping the decisive logic clear.

## 13. Better and Worse Weight Loss Comment Examples

These examples are illustrative rather than signed-off Weight Loss case patterns. They demonstrate style and evidence relationships without creating case precedent.

### General health cues without targetedness

**Prefer**

> The healthy-food and exercise imagery point toward healthy living, but they are too general to establish that the offer is specifically about weight loss or fat reduction. I would rate it No.

**Avoid**

> The ad contains health-related imagery but lacks sufficient categorical specificity.

### Explicit weight-loss purpose

**Prefer**

> The creative explicitly promises weight loss and fat burning through the advertised supplement, so I would rate it Yes.

**Avoid**

> This is clearly aligned with the Weight Loss category.

### Weight-loss-adjacent method with another purpose

**Prefer**

> This is a high-protein plan for athletic preparation. Although diet and fitness can overlap with weight loss, the advertised purpose here is training performance, so I would rate it No.

**Avoid**

> It is diet-related but not the right type of diet.

### Research-resolved exact product

**Prefer**

> [Product] is specifically marketed as an appetite-control weight-loss supplement, and the visible “slim” wording supports that identification. I would rate it Yes.

**Avoid**

> Research shows this is probably relevant.

### Cumulative implicit framing

**Prefer**

> The creative does not say “weight loss” directly, but the combination of appetite control, calorie reduction, and waist-slimming claims specifically points to that purpose. I would rate it Yes.

**Avoid**

> Several clues make this seem health-related, so Yes.

### Unidentified subject

**Prefer**

> The creative only uses vague wellness wording, and research does not identify the advertised product or program. There is too little information to classify it, so I would mark it Unrateable.

**Avoid**

> Not enough Weight Loss evidence, so No.

## 14. Drafting Checklist

Before finalizing a comment, check:

- Did I state what the creative or page promotes?
- Did I state the actual reason for the rating?
- Did I distinguish broad health relatedness from Weight Loss targetedness?
- Did I name the decisive purpose, claim, identity, or missing information?
- If several clues matter, did I explain whether they specifically converge on Weight Loss or only on general health?
- If research materially contributed, did I state the useful verified finding?
- Did I avoid importing another campaign, possible use, or general brand association?
- Did I use direct wording for facts and hedge only the interpretive part?
- Is the comment concise enough for a rating task?
- Could the same comment fit many unrelated creatives? If yes, make it more specific.
- Did I avoid overusing framework vocabulary?
- Does it sound like a person wrote it?
- If I reused optional cross-category language, did I adapt it rather than importing Video Games logic?

## 15. Default Comment Patterns

Use these only as fallbacks when no signed-off pattern expresses the reasoning naturally.

### Yes

> The creative promotes [product/plan/procedure/service] for [weight-loss or fat-reduction purpose]. Since [decisive evidence], I would rate it Yes.

### No — identifiable competing purpose

> The creative promotes [subject] for [general health/fitness/medical/other purpose]. Although [adjacent clue] could be associated with weight loss, this offer does not establish weight loss or fat reduction as its purpose, so I would rate it No.

### No — generic health framing

> The [text/imagery] points toward [healthy eating/activity/wellbeing], but it is too general to establish a weight-loss or fat-reduction offer. I would rate it No.

### Unrateable

> The creative only shows [limited generic clues], and research does not identify what is being advertised. There is too little information to classify it, so I would mark it Unrateable.

### Research-resolved

> [Visible name or wording] refers to [verified identity or meaning]. Since [connection to—or distinction from—a Weight Loss purpose], I would rate it [Yes/No].
